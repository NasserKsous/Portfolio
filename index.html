This was one of the first games I ever made using C++. It was a struggle to get used to step up from Visual Basic (which I learnt in college). It's not a polished game by any means but I am still happy with how it turned out. OpenGL Graphics Engine

This is my first graphics engine made using OpenGL. It has multiple cubes with textures coming towards the screen whilst spinning.
Github link for the Game

Just like the Mario game, this project was a new concept for me. This was the first graphics engine I have ever made and this caused me a few more issues then the mario game. This is because it was my first time coming across the creation of a graphics engine from scratch so I had to learn all the theory behind a graphics engine whilst also how to implement these concepts into a legacy version of OpenGL. I managed to learn the basics well enough to create a project that works but since then I have worked hard on researching the working of a graphics engine and I'm currently working on making one using DirectX which is a massive improvement from this project.

This was my first attempt at making a graphics engine.
